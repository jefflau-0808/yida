# 衣搭交互 Demo

纯前端模拟原型，用于讨论界面及流程，不提供真实 AI 或真实后端。

## 运行
Node.js 22+。无需安装依赖。
- `node server.mjs`：本地 http://127.0.0.1:4173
- `node --test tests/*.test.mjs`：运行测试
- `node build.mjs`：生成 dist 静态站点

## 可体验
上传照片、手动确认模拟标签、自动收录、重复照片复用、相似条目确认、从衣柜选上衣、两套预设推荐、场景选择、已有单品匹配、收藏、编辑／删除、重置示例。

初始衣柜仅两件示例衣物。鞋子以“AI 参考款 · 模拟”展示。参考款图片不是实际生成结果，均为预先准备的素材。清除衣柜候选后结果不再标记“衣柜已有”。

## 原型边界
- 无真实识别、推荐、绘图、登录、云存储或支付。
- 本地 localStorage 保存压缩照片和收藏；空间不足会提示失败。生产版应按设计迁移至 IndexedDB。
- 无 PWA 安装或离线保证，响应式 Web 优先验证流程。
- 不上传图片，未配置后端密钥。
- 两套方案循环展示，界面显示 1 OF 2 / 2 OF 2。
- 预设商品图片仅供原型评审，商业发布前替换或确认素材授权，详见 ASSETS.md。
- WebMCP 在支持浏览器中可选注册；无支持环境时不影响操作。模拟合约测试不等于支持浏览器实测。
- 标准 Sites 安装器因本机 EPERM 路径兼容错误无法运行，因此采用无依赖静态实现。

所有改动随 Git commit 保存，应用测试和构建记录在验证文件中。
